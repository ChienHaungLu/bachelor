# Introduction

## Algorithm
演算法主要為大學部必修課程，存放過往的撰寫作業或專案等

<br>

## C_language_Homework
主要為大學部必修課之C語言課程功課存放區

<br>

## ComputerGraph
主要為大學部選修課程，存放為電腦圖相關的專案製作，過程中有使用到OpenGL的API

<br>

## Database
主要為大學部必修課程，資料庫系統為專案存放區，有與校外公司合作取得商品或合作資料等，因保密協議不提供商品客戶資料

<br>

## Digital-System
主要存放大學部之數位系統課程，本課程作業是透過**VHDL**硬體描述語言進行撰寫，並在QuartusII之EDA設計軟體上進行測試，確保功能的正確性

<br>

## Information Security
主要在學習資訊安全，透過期中報告了解勒索病毒攻擊原理，並透過OffSec進行資安攻防，從中學習可能的資安漏洞攻擊原理，期末project主要在做勒索病毒實際上如何將受害者檔案加密，另外期末project考量本機電腦的安全性，所以期末作業是在虛擬機上完成，避免造成本機因為加密而無法存取特定檔案造成本機電腦作業系統受到影響

<br>

## Senior Project
此為大學部畢業專題檔案存放區，主要的深度學習框架為Pytorch，資料集來源皆和國外作者簽署同意書取得授權!
